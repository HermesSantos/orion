Transpiler for the Orion language to Go, written in Go. A simple, expressive language with its own syntax.

# Usage

Build the transpiler, then transpile .or files to Go.

terminal 
1# Build the transpiler
2go build -o orionc ./cmd/orion/main.go
3
4# Transpile a .or file
5./orionc my_program.or
6
7# Transpile and run
8./orionc -run my_program.or
9
10# View tokens and AST (debug)
11./orionc -debug my_program.or
Tip: Use the -run flag to transpile and run the generated Go program in one step.

# Orion syntax

Orion has static typing, string interpolation, and a unique chained conditional syntax.

# Variables

Declare variables with an explicit type using type name = value.

orion 
1string name = "hermes";
2integer age = 45;
3bool is_male = true;
4float pi = 3.14;

After declaration, reassign with name = value (no type prefix).

orion 
1integer count = 0;
2count = 10;

# Operators

Comparison and logical operators work in if conditions and expressions.

Operator Meaning
== !=Equal / not equal
< > <= >=Ordering
&& || !And / or / not
+ - * /Arithmetic
orion 
1if age == 45 {
2    io::write("match");
3}
4
5if nArr[index] != reversed[index] {
6    ok = false;
7}

# Conditionals

Orion uses if, or_if, and or for chained conditionals — equivalent to if / else if / else in other languages.

orion 
1if is_male {
2    io::write("is male");
3} or_if age > 30 {
4    io::write("older");
5} or {
6    io::write("default");
7}

# Functions

With return value

Functions with a return type use ::(expr) for implicit return (strings support $var interpolation).

orion 
1string helloName (string name) {
2    ::("hello, $name !");
3}
4string hello = helloName("hermes");
5
6bool isPalindrome (integer n) {
7  [integer] nArr = n.toArray();
8  [integer] reversed = [];
9  for index, _ :: nArr {
10    reversed.push(nArr[nArr.length() - 1 - index]);
11  }
12  ::(true);
13}

Void (no return)

Functions without a return type perform side effects such as I/O.

orion 
1writeScreen () {
2    io::write("hello, world");
3}
4writeScreen();
5
6// With parameters (no return type)
7isPalindrome (integer n) {
8    [integer] nArr = n.toArray();
9}

# Arrays

Typed arrays use [T] name = …. Element types include integer, number (alias of integer), and string. Declare from a literal or from any expression.

orion 
1[string] names = ["hermes", "lucas"];
2[number] digits = 12.toArray();
3
4// Iteration
5for index, value :: names {
6    io::write(value);
7}

Indexing & assignment

Read elements with arr[index]. Write to an existing index with arr[i] = value. Use arr:push(x) to grow the array — assignment does not append.

Note: arr[arr.length() - 1] = x replaces the last element; it does not add a new one. To append, use push.
orion 
1[integer] arr = [1, 2];
2[integer] empty = [];
3
4io::write(arr[0]);              // 1
5arr[0] = 3;                        // [3, 2]
6arr[arr.length() - 1] = 9;   // [3, 9]
7arr:push(4);                      // [3, 9, 4]

Array methods

Built-in array operations use arr:method() (colon) or arr.method() (dot) where noted. Transpiles to idiomatic Go (append, len, etc.).

Method Syntax Description
pusharr:push(x)Append a value
poparr:pop()Remove and return the last element
firstarr:first()First element
lastarr:last()Last element
removearr:remove(i)Remove by index
removeValuearr:removeValue(x)Remove first matching value
lengtharr.length() or arr:length()Number of elements
orion 
1[integer] arr = [1, 2, 3];
2io::write(arr.length());   // 3
3arr:push(4);
4arr:pop();
5arr:first();
6arr:last();
7arr:remove(0);
8arr:removeValue(2);

toArray()

Split a string or integer into an array — similar to JavaScript’s split on digits or characters. Call with dot notation: value.toArray(). Assign to a typed array; the element type selects the result shape.

Receiver Target type Result
integer[integer] or [number]Digits as ints (12 → [1, 2])
string[string]One character per element
string[integer]Each character as int (digit chars)
orion 
1integer number = 12;
2[number] arrNumber = number.toArray();
3io::write(arrNumber);   // [1 2]
4
5string text = "hi";
6[string] chars = text.toArray();
7io::write(chars);        // [h i]
8
9// Reverse digits: 12 → [1,2] then push from end → [2,1]
10[integer] nArr = 12.toArray();
11[integer] reversed = [];
12for index, _ :: nArr {
13    reversed.push(nArr[nArr.length() - 1 - index]);
14}

# String interpolation

Variables are interpolated with the $ prefix inside strings.

orion 
1string greeting = "hello, $name !";

# I/O

Input and output via the io:: namespace.

orion 
1io::write("hello, world");
2io::write(variable);
