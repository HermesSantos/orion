Transpilador da linguagem Orion para Go, escrito em Go. Uma linguagem simples e expressiva com sintaxe própria.

# Como usar

Instale e compile o transpilador, depois transpile arquivos .ori para Go.

terminal 
1# Construir o transpilador
2go build -o orionc ./cmd/orion/main.go
3
4# Transpilar um arquivo .ori
5./orionc meu_programa.ori
6
7# Transpilar e executar
8./orionc -run meu_programa.ori
9
10# Ver tokens e AST (debug)
11./orionc -debug meu_programa.ori
Dica: Use a flag -run para transpilar e executar o programa Go gerado em um único passo.

# Sintaxe Orion

A linguagem Orion possui tipagem estática, interpolação de strings e uma sintaxe de condicionais encadeada única.

# Variáveis

Declare variáveis com tipo explícito usando tipo nome = valor.

orion 
1string name = "hermes";
2integer age = 45;
3bool is_male = true;
4float pi = 3.14;

# Condicionais

Orion usa if, or_if e or para condicionais encadeadas — equivalente a if / else if / else em outras linguagens.

orion 
1if is_male {
2    io::write("is male");
3} or_if age > 30 {
4    io::write("older");
5} or {
6    io::write("default");
7}

# Funções

Com retorno

Funções com tipo de retorno usam ::(...) para retorno implícito com interpolação de strings.

orion 
1string helloName (string name) {
2    ::("hello, $name !");   // retorno implícito
3}
4string hello = helloName("hermes");

Void (sem retorno)

Funções sem tipo de retorno executam efeitos colaterais como I/O.

orion 
1writeScreen () {
2    io::write("hello, world");
3}
4writeScreen();

# Arrays

Arrays tipados com sintaxe [T] e métodos encadeados com :.

orion 
1[string] names = ["hermes", "lucas"];
2
3// Iteração
4for index, value :: names {
5    io::write(value);
6}
7
8// Métodos de array
9names:push("gusta");
10names:pop();
11names:first();
12names:last();
13names:remove(0);
14names:removeValue("hermes");

# Interpolação de strings

Variáveis são interpoladas com o prefixo $ dentro de strings.

orion 
1string greeting = "hello, $name !";

# I/O

Entrada e saída via namespace io::.

orion 
1io::write("hello, world");
2io::write(variable);

# Mapeamento de tipos

Orion transpila para Go com os seguintes mapeamentos de tipos:

Orion Go
stringstring
integerint
boolbool
floatfloat64
[T][]T
